# Mac Video Fullscreen — research

## 1. Target audience
Mac users with two or more displays who keep "Displays have separate Spaces" turned off and watch tutorials, lectures or shows in Chrome while working on another monitor **[verified-product]** (dual-screen-video/README.md).

## 2. Main problem
With separate Spaces off, native fullscreen can leave other displays black. The standard advice is to turn the setting on, which changes the whole desktop's behavior **[verified-external]** (https://www.duetdisplay.com/help-center/when-i-fullscreen-an-app-on-my-mac-the-other-screens-go-black; https://forums.macrumors.com/threads/youtube-full-screen-mode-overtakes-external-monitors.2145917, observed 2026-11-05).

## 3. Core promise
"Watch video on one Mac monitor. Keep working on the others." **[verified-product]** (store/LISTING.md; live listing).

## 4. Differentiators
- Moves the real tab into a maximized popup window; original video element stays in place **[verified-product]** (README).
- No native fullscreen request and no new Space **[verified-product]**.
- Automatic access only on YouTube/Netflix; activeTab elsewhere; no analytics **[verified-product]** (store/PRIVACY.md).
- Media shortcuts (volume, mute, speed) and 13 store languages live in v1.3.3 **[verified-external]** (Chrome Web Store, version 1.3.3, updated 2026-11-02, observed 2026-11-05).
